# SolutionArchitectAI

ИИ-помощник solution-архитектора: от бизнес-требований к согласованным потокам данных и межсистемным взаимодействиям.

**Статус:** требования к MVP на согласовании. Реализация продукта ещё не начата.

Основной документ — [BRD MVP](docs/BRD.md): назначение, функции, результаты и критерии приёмки.

| Документ | Для чего читать |
| --- | --- |
| [BRD MVP](docs/BRD.md) | Функции, ограничения, результаты и критерии приёмки |
| [Принципы архитектуры](docs/architecture.md) | Предложения по модели архитектуры, диаграммам и интеграциям |
| [Пример для эталона](docs/examples/reporting-system.md) | Вводные для подготовки ожидаемого результата |
| [Согласование](docs/review.md) | Открытые решения и порядок приёмки |

До реализации подготавливается и согласуется ручной эталон — синтетические входные требования, корпоративный контекст и полный комплект ожидаемых результатов. Его используют для проверки MVP. Предметные вводные вынесены в отдельный документ примера.

Изменения предлагаются в отдельных ветках через pull request. Прямые коммиты в `main` и автоматическое слияние не используются.
