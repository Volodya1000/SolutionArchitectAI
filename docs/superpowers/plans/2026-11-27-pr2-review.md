## Review Focus

- A failed history request cannot masquerade as no previous result.
- Old snapshots retain source versions even when no requirement was extracted.
- A changed model, prompt, scope or selected version never claims unchanged settings.
- Network retry reuses its operation ID; intentional repeat gets a new operation ID.
- Language checks allow source-language technical terminology and share retry budgets.
