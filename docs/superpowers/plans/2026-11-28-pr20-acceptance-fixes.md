## Исполнение

Для каждого дефекта: прочитать путь данных → добавить регрессию → получить
ожидаемое падение → минимальное исправление → целевые проверки. Команды
запускаются из корня с `uv run --locked --project backend` и `pnpm.cmd`.
Итоговая таблица должна содержать дефект, изменение, проверку, фактический
результат и SHA/PR; незакрытое явно остаётся незакрытым с причиной.
