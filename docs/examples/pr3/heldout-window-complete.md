# Журнал событий

События доступны в течение семи суток после регистрации, затем удаляются.

Оператор выбирает день внутри доступного периода и получает события этого дня.
Если событий за выбранный день нет, возвращается пустой список.
Если выбранный день находится вне доступного периода, запрос отклоняется
с указанием первого и последнего допустимых дней.
